买之前先对一下

支持的设备

机械臂之外，还有两样东西决定你能拍到什么：跟焦马达和相机。 这里写清目前支持到什么程度，避免买回来才发现接不上。

跟焦马达 索尼相机 其他相机 怎么确认

一、跟焦马达：支持 Air4 有线马达

目前只支持这一类 —— 有线网络连接的 Air4 控制器。其他品牌或纯无线马达暂不支持。

型号Air4 有线马达。一台控制器可以带两台，软件里分别显示为 Air4 A 和 Air4 B，各自独立绑定、独立排焦点。
连接方式有线网络（以太网）。使用 Modbus TCP，控制器固定端口 60000；连接时填入控制器 IP 地址即可。
需要准备控制器上电并与电脑在同一网段；建议直连网线或独立小交换机，别和办公网混在一起。
不支持的情况纯无线连接的控制器、其他品牌马达、以及通过 USB 直连的马达，当前版本都接不上。

接上之后能做什么

焦点当轨道排焦点可以像机位一样放进时间线，某一帧只想改焦点也不必新增机位。
自动标定一键走完全行程，两端确认后交给软件接管，之后所有位置都按比例对应。
精确重复焦点位置存得住、找得回，换场地重拍也能对上同一条焦点线。
状态可见软件会读回马达位置、限位与故障状态；异常时会在运行提示里说清原因。
注意

标定没做、或马达没被授权接管时，焦点轨道会显示为不可执行 —— 这不是软件坏了，是还没告诉它行程范围。

二、索尼相机：USB 或 WiFi 接入，可控制参数并驱动对焦

支持索尼相机的官方远程控制能力；具体能调哪些项，取决于机身型号与固件。

连接方式USB 或 WiFi 两种。软件里能看到在线设备列表，选中后连接；WiFi 首次连接需要在相机端确认授权。
平台要求需要 macOS 或 Windows 原生应用；iPad 版不支持索尼相机控制。
参数控制快门、光圈、ISO 等常用曝光参数可以在软件里直接调；可调范围与选项由机身决定，软件只显示这台机器支持的项。
录制可以在软件里开始 / 停止录制，并显示当前是否在录。
对焦位置支持按百分比（0–100%）驱动镜头对焦位置，配合时间线做焦点变化；需要相机端授权对焦控制。
实时取景可以把机身画面回传到软件里，用于构图与监看（与机械臂的监看互不冲突）。
两点说明

① 不是所有索尼机型都支持全部功能：老机型可能只能录、不能调参，或只能调参、不能驱动对焦 —— 连上之后软件会按机身实际能力显示。

② 对焦驱动用的是机身自身的对焦系统，镜头需支持相应协议；手动电影镜头通常只能通过马达跟焦，不能走这条路。

三、其他相机怎么用

不接管相机也没问题 —— 机械臂只管运动，相机你自己控制。

不连相机机位、速度、时间线照常排；对焦用跟焦马达手动或按轨道驱动。
其他品牌当前版本不提供其他品牌的参数控制与对焦驱动。
监看相机画面可以通过自己的监视器 / 采集卡看，不影响机械臂运行。

四、买之前怎么确认

1. 马达确认是 Air4 有线控制器，能填 IP、端口 60000；不确定就先问卖家型号。
2. 相机先查你的索尼机身是否支持远程控制（USB 或 WiFi）；接着看它能否被远程驱动对焦。
3. 平台要用索尼相机控制，得在 macOS / Windows 上跑；iPad 只能做机械臂这一侧。
4. 不确定就问把你的机身型号发到微信群里，我按实际能力告诉你哪些能用。

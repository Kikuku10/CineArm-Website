v0.1.46 · 三端同步更新

为影视机械臂而生的
运动编排与控制

CineArm 把运动编排、跟焦与相机控制放进同一个编辑器，让机械臂的每一次运动都可预览、可撤销、可复现。 macOS、Windows 与 iPad 共用编辑器与计算核心，现场换设备不用重学。

macOS 14+ · Apple Silicon Windows x64 iPad（自签安装）

三端同源，一套工作流

各平台独立管理项目、连接与授权，共用编辑器、计算与核心执行逻辑。

◆

跨平台一致

macOS、Windows x64 与 iPad 使用同一套编辑器与计算核心，工程文件与操作习惯保持一致。

◆

可撤销的运动编排

点位编辑明确开始后才进入调整，Undo/Redo 覆盖编辑过程；打开、编辑项目本身不发送运动命令。

◆

跟焦与光学编辑

外部输入接管时保持状态协调，跟焦与光学编辑结果在接管结束后依然保留。

◆

多机型支持

已接入 Nova5、CR5、CR10/CR10A 运动实验参数，以及 Air4 BLE 与末端有线连接。

◆

相机配对

Windows 端相机配对流程已优化，机位与画面参数就近管理，减少现场调试往返。

◆

安全边界明确

原生运动复用安全门禁与唯一 Stop。真机操作前关闭 DobotStudio，并完成现场安全确认。

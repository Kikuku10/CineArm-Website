功能详解 / 记录与编辑：先摆位，再落点

记录与编辑：先摆位，再落点

录音式的节奏：摆好、看一眼、按一下。

追加与插入默认追加到末尾；在中间落点自动插入一段运动区间，后面点位顺延。
播放头拖播放头只改查看时刻，不会让机械臂动；要动设备必须显式定位或发送。
选择与移动框选、多选、移动、复制点位；改起终点时间会连同区间一起重算。
普通预览不接管设备时，用半透明机械臂显示播放头时刻的预想姿态。
光心运镜以镜头光心为基准整体定位机位，适合保持构图、只微调整体的场合。
总览表逐列检查整条镜头的点位、类型、平滑、对焦和目标，比逐个点开卡片快。
快照右键「更新快照」替换图片，「删除快照」只删图保留姿态；旧图不证明当前状态仍相同。
独立概览概览里的区间编号不新增必经点；改时间拖概览标记，检查器里的时间只读显示。

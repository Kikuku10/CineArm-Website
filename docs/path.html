功能详解 / 路径：想要怎么走，五种走法都行

路径：想要怎么走，五种走法都行

想要绕开、穿过还是贴着一个点走，五种走法各管一种。

绕过角点连续运镜不必在每个机位停一下。
串起多点一条连续的线把多个机位连起来。
三点圆弧给定起点、经过点和终点，走出一段稳定的弧。
围绕目标以被摄对象为中心画弧，全程对着它。
自由曲线想要特殊弧线时，自己塑造路线形状。
随时回退任何高级走法都能一键恢复成普通路径。

改完路径等它算完再跑；保存成功不等于可以执行。

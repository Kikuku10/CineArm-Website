发送与安全：到这一步，软件说了不算

前面都是准备，只有发送会让机械臂真的动。

发送轨迹（默认）整段轨迹生成文件上传，由控制柜播放，链路最短、节奏最稳。
全程 ServoJCineArm 持续逐点发送目标，适合需要与软件实时联动的场合。
回起点两种「沿轨迹」走已有路线；「关节运动」直接规划关节，不保证空间上沿原拍摄路径。
上传认证厂商默认或自定义账号，读取并核对主机指纹后验证保存；指纹变化先查原因。
必须先到起点正放先回 I、倒放先回 O，等真实机械臂到位；拖播放头不能代替到位。
运行顺序停预览 → 核对项目与 I/O 和运镜检查 → 选全局速度、首次关循环 → 开发送模式回起点 → 点正放／倒放 → 处理跟焦确认 → 观察到位。
暂停与结束准备或运行中按钮变红色「暂停发送」；可「继续发送」接剩余，或「结束发送」放弃剩余并等解锁。
故障锁「停止状态待核验」时按「检查并恢复控制」重新核对；清除控制柜报警不会清掉本地未确认状态。
四个恢复入口恢复控制、安全退出并关闭运动控制、清除报警、关节箭头点动 —— 各适用不同状态，未知或多重报警不放行动作。
两条边界上传轨迹不是保存项目，别把 .cinearm 塞进控制柜；文件播放用 DO1–DO6 标进度，先核对外设接线。

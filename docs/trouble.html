排错与收工

大部分「不能用」都能在运行提示里找到具体原因，先看提示再动手。

现象先做什么
连不上／一直等状态查线、网卡或 Wi-Fi、双方地址掩码、重复 IP、权限与协议机型，别只猜默认地址。
状态连上但不能控制看许可、型号、报警和静止状态，按连接窗口给出的正常开启或恢复入口处理。
按钮灰／图算不完悬停看原因，开运行提示，等计算；先停播放与输入，处理所选对象和路径规则。
未到 I 却不能正放发送模式点机械臂回 I 并等待 —— 播放头位置不是机械臂位置。
圆弧／平滑失败查连续选择、点位、时间、速度、目标半径和约束，撤销最后一次修改再试。
报警清了仍锁查首个执行错误与停止结果；清柜端报警不清本地未确认状态。
正常收工松开持续输入 → 运行中先暂停等静止再结束 → 扶稳负载、停止拖拽 → 关闭运动控制并等反馈确认 → 结束 Air4 接管 → 停止采集 → 保存项目与备份 → 按厂家流程断电。
关窗不等于断电关闭窗口、软件断开都不代表实体断电；未知状态先处理现场，再导出诊断。
急停优先危险、失联或停止不确定时，用已确认有效的实体急停和厂家流程，软件失焦、断网、关窗都不能代替急停。
诊断导出运行提示详情、复制或本端诊断导出可保留原因；发送前核对其中项目与个人信息。

术语速查

这些词在界面里反复出现，含义固定。

项目 / 场景整份工作 / 其中的一条镜头方案。
姿态 / 区间一个机位 / 两个机位之间的运动。
母版 / 实例可复用的机位 / 它在某处的这一次使用。
播放头 / I・O你正在看的时刻 / 这次运行的范围。
光心 / 重心镜头的视点 / 负载重量集中的位置。
标定 / 接管让马达认识镜头行程 / 允许它现在控制设备。

预览、虚拟运行和现场执行要分别检查，软件里的成功不等于现场安全。

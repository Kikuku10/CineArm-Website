Features in detail / Glossary

Glossary

These words recur throughout the interface with fixed meanings.

TermMeaning
Project / sceneThe whole job / one shot option inside it (a timeline)
Pose / segmentA camera position / the motion between two positions
Saved position / instanceThe reusable master / one placement on a timeline or node
Playhead / I–OThe moment you are viewing / the range this run uses
Smoothing 1 / 2May bypass corners / passes through interior saved positions
Pass-through speed 0An explicit zero; restoring AUTO means clearing the input, not typing 0
Optical centre / centre of massThe lens viewpoint / where the payload weight is concentrated
Calibration / takeoverLearning the lens travel / permission to control the device now
Virtual setThe shooting environment (table, subject, virtual focal length)

Preview, virtual run and on-site execution each need their own check — success in software never replaces on-set safety and the final image.

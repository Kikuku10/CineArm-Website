Features in detail / Glossary

Glossary

Words that recur throughout the interface, with fixed meanings.

Project / sceneThe whole job / one shot option inside it.
Pose / segmentA camera position / the motion between two positions.
Master / useThe reusable position / one placement of it.
Playhead / I–OThe moment you are viewing / the range this run uses.
Optical centre / CoMThe lens viewpoint / where the payload weight sits.
Calibrate / take overTeach the motor the lens travel / allow it to drive the device now.

Preview, virtual run and on-site execution each need their own check; success in software is not on-set safety.

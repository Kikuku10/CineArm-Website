Pricing · updated

Free in full

The old Free / Studio split is gone. There is no paid feature, no subscription and no renewal — what you download is the complete product.

What changed

ItemBeforeNow
Timelines1 in the free tierUnlimited
Pose keyframesUp to 4 in the free tierUnlimited
Projects, virtual arm, preview, savingUnlimitedUnlimited
Real-arm connection, manual control, focusIncludedIncluded
Studio licence¥2,000 one-timeRemoved; features folded into free
One-to-one support¥9,999 separatelyNo longer sold — post issues in the group as before

If you bought Studio before, there is nothing to do — your features stay, and nothing renews.

Why

A paywall blocks the people who need itMost people shooting with an arm have already spent on hardware; a second gate on software turns one barrier into two.
Software should not be the bottleneckThe value is in actually using it. Capping keyframes or timelines only makes people do arithmetic before shooting.
Free makes the docs universalGuides, checklists and pitfalls apply to everyone, instead of first asking which tier you bought.

So is money still needed?

Yes — but only as voluntary support.

Supporting is voluntaryNot supporting changes nothing: not features, not downloads, not updates.
No privilegesThere is no supporter-only feature. Everyone gets identical software.
Where it goesHardware, consumables, signing certificates and bandwidth — the cost of testing features and signing builds.
The listSorted by amount, ties by date — on the acknowledgements page.

Closed source, still free

The application source is not published — but every feature is free, with no paid tier and no subscription. Closed source and paid are two different things; only the first applies here.

Application: closedThe source stays private. It contains a lot of measured-on-real-hardware parameters and edge handling, maintained by one person.
Features: all freeUnlimited timelines and pose keyframes; real-arm connection, focus and output tracks included. Not a trial — no expiry.
Builds and releasesAll versions and checksums live in CineArm-Releases.
This site: openThe website itself is open source: CineArm-Website, plain HTML + CSS.

The camera-plate CAD is public on MakerWorld — that is hardware, unrelated to the software licence.

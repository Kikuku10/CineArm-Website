Shortcut card

CineArm v0.1.46 · default keys (rebind under Preferences → Keyboard) · Print: A4 portrait, scale around 90%

Project and file

Shift1Open the project manager
ModSSave project
ModShiftSSave as

Editing

ModZUndo — edits only, never real motion
ModShiftZRedo (Mod+Y also works)
ModASelect all, scoped to the current selection type
ModCXVCopy / cut / paste
DeleteDelete selection (Backspace works too)

Playback and range

←→Step the playhead one frame
SpacePlain preview play / stop (does not start a send)
IOSet start / end at the playhead
AltIORestore the full range

Timeline view

AltwheelZoom the timeline
ModwheelPan horizontally
ShiftwheelChange track height
Middle-dragMove the timeline view

Recording and audio

KRecord the current pose as a keyframe
ModBInsert a keyframe at the playhead
MAdd a beat marker with the playhead inside an audio clip
M buttonThe button beside the track label mutes the whole track (not a marker)

Modifiers and click semantics

Mod⌘ on macOS, Ctrl on Windows
AltAlso called Option on macOS
HoldJoysticks, return bars, continuous keys: release requests a stop
ClickMove to, move to playhead, paper plane, levelling: keeps going after release
EscAbort positioning, cancel preparation, or end a finite move

Easy to confuse

PlayheadOnly the moment you view — not where the arm is
UndoReverts edits, never motion that already happened
ClosingNot a power-down; a disconnected app is not a safe machine
E-stopOn danger or lost link, use a verified physical E-stop

Rebinding

PreferencesStatus-bar gear → Keyboard → Software shortcuts
BindingsUp to four per command; conflicts list the existing command
PresetsSave, import, export, delete — the default preset cannot be removed

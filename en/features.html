v0.1.46 feature sheet

Features in detail

How the app is structured: what each area does, what each track holds, the five path types and five speed concepts, how focus gets from a curve to a motor, what it takes to send safely — plus shortcuts, preferences and where to look when something refuses to run.

01 Six workspace areas, one job each The app opens the project manager first; inside the workspace these six areas never change role. Read → 02 Projects and scenes: keep more than one answer Project → scene → saved position, so comparing options never means copying the whole job. Read → 03 Saved positions: one master, many instances Recording a pose creates both a reusable master and one use of it — two different things. Read → 04 Five tracks, each holding its own thing Separate tracks mean changing framing cannot silently change focus. Read → 05 Recording: place it, look at it, press once Recording is the most repeated action, so it is a rhythm rather than a dialog. Read → 06 Paths: five ways, differing in what they pass through Same A to B, but the intermediate positions behave completely differently. Read → 07 Five speed concepts, not interchangeable Mixing them up is the usual reason “I changed it but nothing happened”. Read → 08 Targets: lock the framing to one point “Where the lens looks” becomes a reusable object instead of being baked into every position. Read → 09 Node editing: a different way to read a shot The timeline sorts by time; nodes sort by where you go next. Read → 10 Manual control: four inputs, pick what fits Finding a position should not depend on which tool you are holding. Read → 11 Payload and camera tools: data first, precision second The same arm behaves differently with different loads, so this is configuration, not feel. Read → 12 Follow focus: program the curve, then connect the motor Focus is its own timeline — you can program it before any hardware is connected. Read → 13 Monitoring and virtual set Monitoring is the frame you capture; the virtual set is the spatial relationship. Both live in the same 3D view. Read → 14 Audio and rhythm: cut the move to the beat Bring the track in, mark the beats, time the movement against them. Read → 15 Sending: this is where the software stops deciding Everything before this is preparation. Only sending moves the arm. Read → 16 Shortcuts and input devices Defaults cover the frequent actions, and everything can be rebound and saved as a preset. Read → 17 Preferences: six categories, save to apply Open from the gear in the status bar; the search filters by name or keyword. Read → 18 Troubleshooting and wrap-up Most refusals have a concrete reason in the run messages — read it before changing anything.

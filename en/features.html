v0.1.46 feature sheet

Features in detail

How the app is actually structured: what each workspace area does, which tracks exist on the timeline, the path and speed concepts, how focus gets from a curve to a motor, and what it takes to send a move safely.

Six workspace areas, one job each

The app opens the project manager first; once a project is open you land in the workspace. The six areas never change role, so you stop hunting for controls.

Top barArm status, run messages, node/timeline switching, global speed and the project name. Check it before every take.
MonitorThe camera, capture card or virtual camera feed — the frame the camera actually sees.
Trajectory previewThe 3D arm, its path, lens aim, snapshots and set, seen from a bystander's angle.
Timeline / node areaPositions, timing, connections, motion and audio — switch between the two views freely.
InspectorParameters for the selected object, or the free control, target, focus and preset pages. Select first, then edit.
Status barJoint angles (J1–J6), position (XYZ, mm) and orientation (Rx/Ry/Rz, °), plus the playhead pose. “—” means no data, not zero.

Preferences can switch the status bar to joint-limit readout; panels can be dragged, collapsed and resized.

Projects and scenes: keep more than one answer

A shot is rarely right the first time, so the structure is project → scene → saved position.

ProjectOne shoot, holding every scene, position, audio file and setting. Manual save, live save and save-as are all available.
SceneMultiple timelines inside one project. Copy a scene to test another route without touching the original.
Saved positionsReusable position masters. Deleting a card on the timeline does not delete the saved position — you can insert it again.
SnapshotsA still of the framing at one moment, for remembering where the camera was. Visibility is a preview option.
BackupProject and audio back up together at directory level, independent of the app running.
Undo boundaryUndo reverts edits only — it cannot undo motion that already happened on the arm. Worth remembering from the first time you take over a real robot.

Five tracks, each holding its own thing

Because the tracks are separate, changing the framing will not silently change focus, and hiding a track never deletes data.

Overview trackSnapshots and numbers — remember a shot by the frames it passed through.
Pose trackThe positions themselves and the move between them; the backbone of the shot.
Target trackTarget assignments and the range where “always aim at” is active.
Focus trackFocus over time. You can insert focus-only keys without touching pose.
Audio trackImported audio, used for timing and beat markers.
Curve viewsCombined speed and focus speed expand into curve views — read the whole rhythm or pull a single segment.

The toolbar covers daily work: undo/redo, multi-select, three levelling modes, go to playhead, start/stop drag, record, send mode, back to start, reverse play, stop, play, jump to end, loop, zoom, snap and track visibility. While the arm is running it becomes red pause / continue / end controls. Hover for exact names.

Recording: place it, look at it, press once

Recording is the most repeated action, so it is built as a rhythm rather than a dialog.

Append or insertNew records append by default; dropping one in the middle inserts a move segment and shifts later points.
PlayheadDragging the playhead only changes what you are looking at. The arm moves only on an explicit positioning or send.
Select and moveBox select, multi-select, move and copy points; changing start or end time recomputes the segment.
Plain previewWithout taking over hardware, a semi-transparent arm shows the intended pose at the playhead.
Optical-centre positioningReposition the whole rig around the lens's optical centre — useful when framing must hold while the rig shifts.
Overview tableScan every point's type, smoothing, focus and target in one table instead of opening cards one by one.

Paths: five ways from A to B

They differ mainly in whether the path still passes through the original intermediate positions.

Smoothing · mode 1Rounds off corners as the path sweeps through them — allowed to bypass the original corner points.
Smoothing · mode 2One continuous path that passes through several saved positions, for multi-point flowing moves.
Three-point arcStart, a via point and end define the arc. It passes through the via position, which does not set rotation on its own.
Arc around a targetTwo equal-radius positions orbit a shared target along the shortest arc in a fixed plane, aiming at it throughout.
Manual cubic BézierShape the route between two points with spatial handles; the path need not pass through the control points.
Roll to horizontalConstrain a saved path's roll to level so long moves do not end up tilted.

After changing path, timing, speed or target, wait for the full recompute before trusting the preview. A successful save does not mean a safe run.

Five speeds that are not interchangeable

There are five distinct speed concepts in the app. Mixing them up is the usual reason “I changed it but nothing happened”.

Jog speedManual speed for free and target control; affects only the current manual action.
Global speedA 1%–100% slider that scales this send proportionally without altering saved timing — made for a first run.
Segment speed curveThe saved ramp: start, accelerate, cruise, decelerate. This is the shot's own rhythm.
Smoothing pass-through speedThe continuous speed while crossing an intermediate position — automatic or manual.
Node speedThe 1%–100% on a node card: an estimate of maximum speed arriving there. Changing it re-times the node.
What the percentage meansAll of these are estimated ratios, not tip mm/s and not measured feedback. Focus speed is a rate of focus change.

Global speed can return to 100% after ending, stopping or reopening a project — check the current value before the next run.

Targets: keep the framing locked to one point

“Where the lens should look” is pulled out of each position and turned into a reusable target.

Reusable targetA point in space that several positions and segments can reference. Change the target and the whole move re-aims.
Hunting positionsWith the target fixed, move the arm around it until the framing is right — it always looks at the same point.
Always aimSet the range where a target applies, so the lens aims at it for the whole move, not just at the endpoints.
Multiple assignmentsDifferent segments can use different targets, or release the lock for a deliberate look-away move.
With arcsThe arc-around-target mode expects both positions at equal radius, which keeps the curve and speed well behaved.
In node editingNode cards can carry their own target and focus, and inherit the route's aim.

Node editing: a different way to read a shot

The timeline sorts by time; nodes sort by where you go next. Complex shots read better as connected cards.

Cards and linksEach card is a position; links are routes. Record, connect and choose a route without renumbering anything.
Motion typeCards show joint, straight, target arc or three-point arc, so a segment's behaviour is visible at a glance.
Smoothing 0–100Strength of mode 1. Zero restores a stop at the original corner; arc via points are limited.
Speed presetsConstant move or ease-in-out across the whole move. Inherited curves can show “keep original curve”.
Stop when passingPass the actual smoothed position at zero speed — not the same as returning to the corner, and it adds no dwell.
Paper-plane positioningClick to drive the arm to that node along the currently available route, release to stop, Esc to abort. Disabled without a device.

Changing card speed re-times the node; with smoothing above zero a speed-only change re-times with full ease-in-out — pick the preset explicitly if you want constant speed.

Manual control: four inputs, pick what fits

Finding a position should not depend on which tool you happen to be holding.

Numeric entryType joint angles or tip position directly — for exact repeatability and for levelling the camera.
DraggingDrag the arm in the 3D view and watch the frame as you go; the quickest way to find a look.
Keyboard and gamepadKeyboard for nudges, gamepad for continuous pushes. Both feed continuous control for long, smooth moves.
Nudge and write backAdjust slightly around a selected point, then write the result back — no need to record a new position.
Preset posesDefault initial pose and the CR5 packing pose can be previewed then executed — one press to park the rig.
Speed and limitsManual motion follows jog speed; near a joint limit the status bar tells you which axis is close.

Payload and camera tools: data first, precision second

The same arm behaves differently with different loads, so this is a configuration — not something you compensate for by feel.

Four inputsPayload weight, centre of mass, camera and lens basics, and rig info. Fill these in and path and speed start to mean something.
Create and editBuild, select, duplicate and edit several configurations, so changing bodies on set does not mean changing projects.
Nova 5 bare-flange baselineNova 5 ships a baseline configuration to start building a load from zero.
Loaded auto-identificationWith the real load mounted, run an identification pass so the software uses measured inertia rather than nominal figures.
Camera levellingLevel the camera with numeric entry; roll and pitch stay readable in the interface.
PresetsConfigurations are saveable and reusable — swap a lens or body by editing one entry.

Follow focus: program it here, connect the motor there

Focus is its own timeline. You can program it without any hardware, then calibrate and take over on set.

Two representationsPercentage 0%–100% or logical code 0–16383 — both are positions along the same calibrated travel, not metres and not focal length.
DirectionNormal or reversed for different mounts. Set before takeover; locked during playback, takeover and calibration.
Focus-only keysInsert a focus-only keyframe at a valid integer frame so focus changes without touching pose.
Focus speed curveFlatten or ramp the platform and transitions. %/s is a project focus rate, not measured lens speed.
Auto-calibrationOne press sweeps the full travel. Watch both ends finish, then confirm — confirming takes over the current target and the motor may move.
Multiple motorsBluetooth devices are distinguished by full identity, not display name. Add, calibrate and take over each one separately.

Reopening a project keeps the binding but not the connection or authorisation; after switching machines, verify identity and rebind. Undoing a project does not guarantee the motor returns to its previous position.

Monitoring and virtual set: see it before you shoot it

Monitoring covers the frame you capture; the virtual set covers the spatial relationship. Both live in the same 3D view.

SourceCamera, capture card or virtual camera, switchable per setup. The virtual camera exists in virtual mode only.
TransformCapture and output scale X/Y, rotation, horizontal and vertical flip. Display only — it does not change the recording.
Grid and centre markRule-of-thirds grid and a centre cross, both recolourable, for judging balance quickly.
Safe area50%–100% range with mask opacity to check frame edges. It is a framing reference, not physical collision avoidance.
PeakingHighlights sharp edges with adjustable sensitivity and colour. It does not replace autofocus or rangefinding.
Virtual setPlace a table, a subject and a virtual focal length to judge the arm-to-subject geometry before you arrive on set.

There is currently no false colour, zebras, waveform, monitor recording or lens library — those are known boundaries, not hidden features.

Audio and rhythm: cut the move to the beat

Bring the track in, mark the beats, and time the movement against them.

Import and auditionAudio plays back on the timeline in sync with the playhead.
Clip editingTrim, move and delete clips, then place movement against the cut.
Beat markersDrop markers on the waveform and align key positions to them; changing the track does not force a full re-time.
Kept with the projectAudio is stored in the project and travels with the backup, so nothing needs re-linking on another machine.

Sending: this is where the software stops deciding

Everything before this is preparation. Only sending moves the arm, so each step has explicit preconditions.

Send trajectory (default)Generates the whole trajectory file and uploads it for the controller to play. Shortest link, steadiest rhythm.
ServoJ throughoutCineArm streams targets point by point — for setups that need live coupling with the software.
Two ways back to startAlong the trajectory, or a pure joint move — the joint move does not guarantee retracing the shot's spatial path.
Controller upload authenticationVendor default or custom credentials, read and verify the host fingerprint, then validate and save. If the fingerprint changes, investigate before overwriting.
Must be at this run's startThe arm has to be at the start position this run expects; otherwise it is refused. That gate is about safety, not permissions.
Pause, stop, recoverPause mid-run and continue from where you stopped; faults get a dedicated recovery path so the arm is never stranded mid-move.

Two boundaries worth stating: uploading a trajectory is not the same as saving a project — do not copy a .cinearm file into the controller; and file playback marks progress on DO1–DO6, so check what those outputs are wired to before relying on them.

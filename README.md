## 这个仓库是什么

纯静态站点（HTML + CSS），部署在 GitHub Pages，绑定自定义域名 `cinearm.top`。
**没有构建步骤** —— 改完直接推 `main`，大约一分钟自动发布。

## 维护约定

- **改样式**：`assets/site.css`，然后把全站 `site.css?v=N` 统一加一，避免浏览器用旧缓存。
- **下载区版本**：首页会自动拉取 GitHub Releases 里最新的已发布版本（**包含预发布**，只跳过草稿）并改写版本号与下载链接；静态值只是兜底，一般不用手动改。
- **功能详解页**：由仓库外的构建脚本生成（`doc_content.py` → `build_v2.py`），不要手改 `docs/*.html`。
- **导航**：全站统一 8 个入口，顺序固定，由脚本一次性写入所有页面。
- **新增页面**：记得同时补 `en/` 镜像与 `hreflang`。

### Stack

Plain HTML + one CSS file, served by GitHub Pages with a custom domain.
No build step — push to `main` and the site updates in about a minute.

```sh
python3 -m http.server 8000   # local preview
```

### Editing notes

- Styles live in `assets/site.css`. After editing, bump `site.css?v=N` across all pages to bust the cache.
- The `docs/` pages are generated by an external script; do not hand-edit them.
- All pages share the same 8-item navigation; keep `en/` in sync with the Chinese pages.
